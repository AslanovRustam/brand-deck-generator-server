# Brand Deck Generator — локальный запуск с реальным AI

## Зачем это отдельно от одного HTML-файла
Ключ OpenAI живёт только на бэкенде (`.env`) и никогда не попадает в браузер.
Страница стучится на свой же адрес (`/api/text`, `/api/image`) — без CORS вообще.

## Запуск

```bash
npm install
# .env уже лежит с фейковым ключом-заглушкой — откройте и впишите свой реальный
npm start
```

Открыть http://localhost:3000.

## Механика по экранам

1. **Titlepage** — лого из формы копируется как есть. Без AI.
2. **Legend** — vision-запрос (`gpt-4o` + картинка лого) по `PROMPTS.legend`,
   ответ ожидается как HTML (`<p>`/`<b>`), вставляется напрямую в слайд.
3. **Color Palette** — сначала пробуем AI-экстракцию цветов (vision,
   `PROMPTS.paletteExtract`, ответ парсится по regex `#RRGGBB`). Если AI
   не ответил валидными кодами — откат на код-экстракцию (canvas-квантование
   для PNG/JPG, regex по `fill`/`stroke` для SVG).
4. **Color Logo Variations** — без AI: реальные извлечённые цвета из
   экрана 3 + лого из формы, код сам решает, где инвертировать лого под
   тёмный/светлый фон.
5. **Symbol** — 3 отдельных вызова `callOpenAIImage` (по одному на плитку,
   каждый — своя пара цветов из палитры), промпт `PROMPTS.extractSymbol`.
6. **Pattern** — 6 отдельных вызовов (3×2 сетка), промпт `PROMPTS.pattern`.
7. **Banners** — 4 отдельных вызова, один на формат (wide / wide-alt /
   square / tall), промпт `PROMPTS.banner`.
8. **Example** — 1 вызов на весь мокап лендинга, промпт `PROMPTS.landingExample`.
9. **Thank you** — статичный, без AI.

Каждый вызов картинки — самостоятельный `images.edits`-запрос с логотипом
как референсом (`referenceImageDataUrl`) и явным уточнением "сгенерируй
только ОДНУ эту плитку", а не весь ряд — так и получается нужное количество
картинок под конкретную вёрстку.

## Если AI недоступен (нет ключа / ошибка / нет доступа к gpt-image-1)
Каждый шаг обёрнут в try/catch и падает на аккуратный фоллбэк:
- Legend → плейсхолдер-текст.
- Palette → код-экстракция вместо AI.
- Symbol/Pattern/Banners → серая плитка на месте конкретной неудавшейся картинки
  (остальные, которые получились, показываются нормально).
- Example → старый кодовый мокап вместо картинки.

## Структура
```
server.js         — Express-сервер + прокси к OpenAI (/api/text, /api/image)
public/index.html — страница генератора, все PROMPTS.* уже заполнены
.env / .env.example
```

## Важно про gpt-image-1
`/api/image` всегда шлёт референс лого → `images/edits`. Для этого у ключа/
организации должен быть доступ к `gpt-image-1` — иначе 403 и фоллбэк на серую
заглушку по этой конкретной плитке.
